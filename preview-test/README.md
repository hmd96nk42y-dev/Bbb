A copy of the BUBL guest web app (`ushuaia/`) and of BUBL OPS (`ops/ushuaia/`) in TEST mode: they talk to bubl-staging, with test cards and no real booking or charge.
bubl concierge's buttons open the guest app from here. It is written by `scripts/publish-test-preview.sh` in the BUBL platform repository and replaced each time: do not edit it here.
The demo copy is in `preview/`, and Sk's builds, the source of truth for the design, are the files next to these folders. None of them is touched.
